## 9‑Box Talent App (web)

### Setup
1. Copy `.env.local.example` to `.env.local` or set the following in `.env.local`:

```
NEXT_PUBLIC_SUPABASE_URL=your-project-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

2. Apply SQL migrations under `../supabase/migrations` to your Supabase (or local Postgres). The minimum are:
   - `0001_init.sql`
   - `0002_seed_box_definitions.sql`

3. Install dependencies and run dev:

```
npm install
npm run dev
```

### Features (MVP)
- CSV import of employees and departments
- 9‑box drag‑and‑drop grid
- Distribution summary and export (PNG, CSV)
