This integration enables AI assistants (like Claude) to interact directly with Supabase databases, providing a standardized interface for managing tables, querying data, and performing database operations. Open Claude Desktop 2. Navigate to Settings > Connectors 3. Click "Add custom connector" at the bottom 4. Enter your Supabase MCP server URL: 5. (Optional) Click "Advanced settings" to configure OAuth 6. Click "Add" to finish Note: Remote MCP servers added via Settings UI cannot be configured through claude_desktop_config.json .
