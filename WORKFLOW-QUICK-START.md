## 🎯 What You Can Do Right Now

### 1. View the Workflow Pipeline

**Steps:**
1. Open app: `npm run dev`
2. Click **Workflow** tab in navigation
3. See all employees organized by workflow stage

**You'll See:**
- 7-column kanban board (one per stage)
- Bottleneck alerts (if any stages are blocked)
- Velocity metrics (how fast you're moving talent through)
- Employee cards sorted by time stuck

### 2. Identify Bottlenecks

**What to Look For:**
- **Red-highlighted columns** = Bottleneck detected
- **Large numbers** in one column = Many people stuck
- **High "days average"** = People stuck a long time

**Quick Actions:**
- Click "Send reminders" → Bulk notify managers/employees
- Click "View employees" → See filtered list
- Click "Escalate" → Alert VP HR

### 3. Track Individual Employees

**On Any Employee Card:**
- See workflow progress bar (e.g., "43% - Step 3/7")
- Current stage shows: "👤 Manager Review"
- Days in stage: "18 days in stage ⚠️"
- Next action: "Complete manager review"

**How to Use:**
- Red warning (⚠️) = Stuck >14 days, needs attention
- Green checkmarks = Completed stages
- Blue progress bar = Overall completion

## 🔄 The 7 Workflow Stages

| Stage | Icon | What It Means | Next Action |
|-------|------|---------------|-------------|
| **Assess** | 📊 | Place on 9-box grid | Drag to grid position |
| **Self Review** | ✍️ | Employee self-assessment | Send review invite |
| **Manager Review** | 👤 | Manager performance review | Complete review |
| **Calibrate** | 🎯 | Cross-functional alignment | Calibration session |
| **Plan** | 📋 | Development plan created | AI draft plan |
| **30-Day** | ⏱️ | First progress check-in | Schedule 1:1 meeting |
| **90-Day** | 📈 | Quarterly review | Monitor ongoing |

## 🤖 Auto-Advancement Features

### When Self-Review Completes:
- ✅ Workflow detects completion
- 💡 AI Coach suggests: "Complete manager review for Alex"
- 🔗 Click → Opens review modal
- ⏭️ Review saves → Employee advances to next stage

### When Manager Review Completes:
- ✅ Both reviews now done
- 💡 AI Coach suggests: "Alex is ready for development plan"
- 🔗 Click "AI draft plan" → Opens with suggestions
- ⏭️ Plan saves → Employee advances to execution

### When Development Plan Created:
- ✅ Plan stage complete
- 💡 Reminder set: "30-day check-in for Alex"
- 📅 In 30 days → Notification to schedule 1:1
- ⏭️ Check-in done → Advances to monitoring

## 🔥 Power User Tips

### Tip 1: Use Bottleneck Alerts Proactively
- Check Workflow tab at start of week
- If bottleneck detected → Clear it immediately
- Don't let 10+ employees pile up at one stage

### Tip 2: Watch the Velocity Metrics
- Track week-over-week improvement
- Celebrate when "Avg Time to Plan" decreases
- Share metrics in leadership meetings

### Tip 3: Pin Stuck Employees
- Find employees with ⚠️ warning
- Pin them to context bar
- Take action to unblock them

### Tip 4: Use AI Coach Suggestions
- AI detects bottlenecks automatically
- Suggests bulk actions (send 23 reminders)
- Follow suggestions to maintain flow

### Tip 5: View from Multiple Angles
- **Workflow tab** → See pipeline stages
- **Calibrate tab** → See issues per employee
- **Employee cards** (anywhere) → See individual progress
