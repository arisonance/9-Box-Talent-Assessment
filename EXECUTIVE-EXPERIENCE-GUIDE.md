## Key Interaction Patterns

### Pattern 1: Suggestion Click
```
User clicks: "Add performance reviews for 3 members"
     ↓
Review modal opens with Sarah Chen pre-selected
     ↓
User completes review and saves
     ↓
Modal closes, returns to dashboard
     ↓
Suggestion shows ✅ checkmark
     ↓
Counter updates: "1 of 5 completed today"
```

### Pattern 2: Section Collapse
```
User clicks: "⚡ QUICK WINS" header
     ↓
Section collapses (shows count badge)
     ↓
User clicks again → Section expands
```

### Pattern 3: Daily Reset
```
Monday: "2 of 5 completed today"
     ↓
(Time passes)
     ↓
Tuesday: "0 of 3 completed today" (fresh start)
     ↓
Different suggestions (based on new team state)
```

## Design Principles Applied

1. **Progressive Disclosure**
   - Advanced features hidden until needed
   - 9-box grid in Insights tab, not first screen

2. **Clear Next Action**
   - Always visible suggestion panel
   - One-click to start any task

3. **Time-Respecting**
   - Estimates shown (~10 min)
   - Can batch similar tasks

4. **Visual Progress**
   - "X of Y completed today"
   - Checkmarks for completed items
   - Stats update in real-time

5. **Contextual Guidance**
   - Different suggestions based on data state
   - Adapts to 360 status (pending vs complete)

6. **Rewarding**
   - Completion counter provides dopamine hit
   - Green checkmarks feel satisfying
   - Progress bars fill up

## What Makes This Work

1. **Single Entry Point**
   - One clear path: Launch 360s
   - No decision paralysis

2. **Guided Discovery**
   - Wizard → Dashboard → Suggestions
   - Each step teaches the next

3. **Visible Progress**
   - "0 of 5 completed today"
   - Green checkmarks
   - Completion percentage per employee

4. **Smart Prioritization**
   - Quick wins first (5-10 min)
   - Build context next (15-30 min)
   - Analysis when ready (requires data)

5. **Respect for Time**
   - Time estimates on everything
   - Can batch similar tasks
   - Skip wizard if busy

6. **Consistent Design**
   - Employee cards look the same everywhere
   - Color-coded categories
   - Familiar modal patterns
